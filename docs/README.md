# Villa Tortuga — paquete inicial de contenido y producto

Este directorio convierte el anuncio público de Airbnb de Villa Tortuga en una base de trabajo para una web propia en inglés y español.

## Documentos

1. [01-airbnb-source-audit.md](./01-airbnb-source-audit.md) — inventario factual, comodidades, reglas, señales de confianza, galería y contradicciones detectadas.
2. [02-bilingual-content.md](./02-bilingual-content.md) — contenido editorial y UX propuesto en inglés y español.
3. [03-prd.md](./03-prd.md) — PRD del sitio, alcance MVP, requisitos, analítica, SEO, accesibilidad y criterios de aceptación.
4. [04-reviews-module.md](./04-reviews-module.md) — contenido, diseño funcional y reglas para mostrar calificaciones y reseñas con enlace a los originales en Airbnb.

## Fuente y fecha de corte

- Fuente principal: [anuncio de Airbnb](https://www.airbnb.com/rooms/1516054436387600999)
- Capturado: 17 de septiembre de 2026, zona horaria America/New_York.
- La disponibilidad, precios, número de reseñas, calificaciones, categoría de Superhost y políticas de cancelación son datos dinámicos. No deben publicarse como valores permanentes sin fecha de actualización o sincronización.

## Estado

La información pública fue recopilada y normalizada. Antes de publicar la web todavía hace falta confirmar decisiones del propietario, resolver contradicciones de seguridad y obtener las fotografías originales con autorización de uso.
