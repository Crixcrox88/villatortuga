## 2. Recomendación para la web

Sí, las reseñas deben mostrarse. Son una de las mejores señales de confianza de la propiedad. La sección debe sentirse propia de Villa Tortuga y llevar al visitante a Airbnb cuando quiera comprobar el contenido completo.

### Estructura recomendada

1. Encabezado con una frase editorial.
2. Calificación general y cantidad de reseñas.
3. Nota de fuente y fecha de actualización.
4. Seis subcalificaciones en una cuadrícula compacta.
5. Temas más mencionados como etiquetas.
6. Cuatro tarjetas destacadas en desktop; carrusel accesible en móvil.
7. CTA para leer las 28 reseñas originales en Airbnb.

### Diseño funcional

- Fondo claro y amplio, acorde con la estética de la villa.
- Número 5.0 como elemento principal, sin copiar laureles o insignias de Airbnb.
- Las subcalificaciones deben usar barras sencillas o valores numéricos propios.
- Las etiquetas de temas deben ser estáticas y no parecer filtros si no realizan una acción.
- Las tarjetas deben mostrar nombre, contexto del viaje, mes/año y síntesis.
- Usar iniciales dentro de un avatar neutral; no copiar fotos de perfil.
- En móvil, una tarjeta completa por pantalla con botones anterior/siguiente accesibles.
- El CTA externo debe indicar que abrirá Airbnb.

## 8. Datos y actualización

Modelo mínimo:

```ts
type ReviewsSummary = {
  source: "Airbnb";
  sourceUrl: string;
  observedAt: string;
  rating: number;
  reviewCount: number;
  recognition?: string;
  subratings: Record<string, number>;
  topics: Array<{ id: string; count: number }>;
};

type FeaturedReview = {
  id: string;
  publicName: string;
  stayContext: "family" | "group" | "short-stay";
  month: string;
  sourceLanguage: "en" | "es";
  approvedCopy: { en: string; es: string };
  sourceUrl: string;
};
```

### Política de actualización

- Revisar rating y conteo antes de cada lanzamiento importante.
- Revisar manualmente una vez al mes mientras el sitio muestre cifras.
- Guardar `observedAt` junto a los datos.
- Si no se puede confirmar el dato, ocultar el número y mantener el CTA a Airbnb.
- No extraer ni actualizar reseñas automáticamente sin una fuente o permiso autorizado.

## 9. Criterios de aceptación

- La sección aparece en inglés y español con significado equivalente.
- Airbnb se identifica claramente como fuente.
- Rating, conteo y reconocimientos incluyen fecha de actualización.
- Se muestran entre cuatro y seis reseñas seleccionadas.
- Cada tarjeta indica si es una síntesis editorial o una cita autorizada.
- El CTA abre las reseñas originales en Airbnb.
- No se copian fotos de perfil, laureles, logotipos, insignias o composición visual de Airbnb.
- El carrusel funciona con teclado, gestos, lector de pantalla y `prefers-reduced-motion`.
- Los datos se ocultan de forma elegante si quedan desactualizados.
